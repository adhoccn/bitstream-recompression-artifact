## Reproducing every number

```
python scripts/validate_signature.py        # Theorem 1, Prop 1
python scripts/validate_comb_structure.py   # occupancy structure
python scripts/validate_fusion.py           # Theorem 5, Prop 7
python scripts/measure_deblock_sigma.py     # Table I
python scripts/make_figures.py              # all simulation figures
```

Each script prints the numeric values it plots (rather than only drawing
them), so every quoted figure in the manuscript can be checked from stdout.
